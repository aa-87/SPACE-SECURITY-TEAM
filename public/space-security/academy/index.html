ENVIRONMENT / REFERENCE
From examples to real programs.
1. Install YottaDB
YottaDB is our chosen MUMPS implementation. Follow the official installation and environment documentation for your Linux system. Use a separate learning environment, not a production database.
2. Enter Direct Mode
In your configured YottaDB shell, run:
yottadb -direct
At the YottaDB prompt, type the following instruction and press Enter. The prompt itself is not part of the instruction.
WRITE "Hello, world!",!
Type HALT to leave Direct Mode. The shell command and prompt are YottaDB environment details; WRITE and HALT are language commands.
3. Save a routine
Create HELLO.m in your configured routine directory. Preserve the leading space on command lines.
HELLO ; My first routine
 SET name="Alex"
 WRITE "Hello, ",name,!
 QUIT
From your configured shell, execute:
yottadb -run ^HELLO
Language policy
Our lessons use standard MUMPS constructs, with full command names. YottaDB-specific commands, functions, and environment configuration are labeled when introduced. Formal ANSI/ISO conformance has not been independently certified.
